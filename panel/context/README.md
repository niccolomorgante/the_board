# Optional supporting material

Supplementary tables, prior analyses, the protocol, data-access agreements, earlier
referee reports — anything that might substantiate a claim in the manuscript.

**The referees never read this directory.** That is deliberate: a reviewer who has seen
your supplementary material is not simulating a referee, they are simulating a co-author.

Only `board-triage` reads it, and only for one purpose: checking whether a finding marked
NEEDS EVIDENCE is actually answerable from something you already have. That check turns
more unfixable findings into five-minute fixes than anything else in the pipeline.

This directory is gitignored.
